# Contributing

Thanks for your interest in Amalgame.

## External contributions are paused

Amalgame is currently developed solely by Bastien Mouget. To keep
the project's direction tight while it's still finding its shape,
**outside pull requests are not being accepted at this time**.

Concretely, that means:

- PRs from forks will be closed without review.
- Feature requests filed as issues will be read but probably not
  prioritised against the public roadmap.
- The repository is kept public so anyone can read the source,
  fork it under the Apache-2.0 licence, and use Amalgame in their
  own projects.

This is a *current* policy, not a permanent one. The author may
reopen contributions later — most likely once the language
reaches feature stability and the contribution surface is easier
to scope (governance, code review bandwidth, testing
infrastructure all need to scale together). When that changes,
this file will be updated and an issue announcing the policy
shift will be pinned to the repository.

## What you *can* do

- **Use the language.** Build something with it. The strongest
  signal of interest is real-world usage.
- **Open a bug report** if you hit a clear-cut bug (`amc`
  crashes, generated C doesn't compile, a documented feature
  doesn't work). Use the issue tracker — bug reports are
  welcome even while contributions are paused.
- **Fork it.** Apache-2.0 lets you make your own derivative; the
  only ask is the NOTICE preservation per the licence text.
- **Tell the author.** If you'd like to be notified when
  contributions reopen, watch the repository or follow releases.

Thanks for understanding.

— Bastien Mouget
